# AI CV Analyzer

## Project Description
An AI-based system that compares a CV with a job description.

## Main Features
- Overall Match Score
- Strong Skills
- Partial Match
- Missing Skills
- TF-IDF Similarity
- Sentence Transformers Similarity
- Comparison between both methods
- Recommendations to improve the CV
- Comparison table using the same test cases

## Technologies
- Python
- Scikit-learn
- Sentence Transformers
- PyMuPDF
- Streamlit
